# Voxy

## PLEASE FOR THE LOVE OF GOD DON'T BOTHER THE FINE PEOPLE ON CORTEX DISCORD WITH BUGS RELATING TO THIS, NO SUPPORT FOR BACKPORTS WILL BE GIVEN

Distant terrain for Minecraft 1.21.1.

## Download

Get the jar from [Releases](https://github.com/notmugi/voxy_ports/releases).

## Requirements

- Minecraft 1.21.1
- Java 21
- Fabric Loader
- Fabric API
- Sodium 0.8.13

## Build

```sh
./gradlew build
```

The jar is in `build/libs`.
